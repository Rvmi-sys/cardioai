# CardioAI

A student machine-learning project comparing heart-disease classifiers on a 920-record dataset derived from the UCI Heart Disease collection. This is a retrospective educational exercise, **not a clinical screening or diagnostic tool**.

## What is included

- `data/heart_disease_cleaned.csv`: cleaned 920-row dataset used by the models.
- `modelling.py`: from-scratch Python implementations of logistic regression, k-nearest neighbours and a decision tree, with an 80/20 stratified split and five-fold logistic-regression cross-validation. The text category `thal` is encoded numerically so the provided dataset runs.
- `visualisation.py`: separate scikit-learn workflow generating 13 figures and a results CSV.
- `figures/`: figures generated by the visualization workflow.
- `legacy/preprocessing_original.py`: the original preprocessing script, kept for provenance. It requires the separate raw `heart_disease_uci.csv` download and does not reproduce this cleaned dataset exactly.

## Run

From the repository root, with Python 3:

```bash
python modelling.py
python -m pip install -r requirements.txt
python visualisation.py
```

The scripts write `model_results.csv`, `model_results_viz.csv`, and regenerated figures. The two workflows use different model implementations and train/test splits, so their figures and scores should be reported separately.

## Results from the supplied cleaned data

| Workflow | Model | Accuracy | Recall | F1 | ROC AUC |
| --- | --- | ---: | ---: | ---: | ---: |
| From scratch | Logistic regression | 0.842 | 0.901 | 0.863 | 0.911 |
| From scratch | k-NN | 0.826 | 0.881 | 0.848 | 0.916 |
| From scratch | Decision tree | 0.875 | 0.901 | 0.888 | 0.924 |
| scikit-learn visualization | Logistic regression | 0.859 | 0.891 | 0.874 | 0.927 |
| scikit-learn visualization | k-NN | 0.826 | 0.842 | 0.842 | 0.896 |
| scikit-learn visualization | Decision tree | 0.864 | 0.891 | 0.878 | 0.896 |

These are results on one held-out split per workflow. The original report called logistic regression the best model using approximate values; these executable results do not support that claim for F1. The logistic-regression five-fold CV F1 in the from-scratch workflow is 0.868 ± 0.027.

## Limitations

Missing values were imputed before the train/test split in the supplied cleaned data, which can leak information. Highly incomplete `ca` and `thal` fields deserve particular caution. There is no independent external validation, calibration study, prospective study, or clinical deployment. Coefficients are descriptive model associations, not proof that a feature causes disease.
